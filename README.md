# 📦 Smart Ledger

**Smart Ledger** is a modern, self-hosted family and workshop inventory management application built with **React Native (Expo)**, **TypeScript**, and **Firebase**. Designed to keep track of home inventory, tools, spare parts, and vehicle maintenance (garage fleet).

## ✨ Key Features

- **Inventory Management:** Organize items by categories and subcategories with custom names, prices, currencies, and store tags.
- **Barcode & OEM Scanner:** Built-in device camera barcode scanner to instantly scan item barcodes or lookup product details.
- **Quick Category Creation:** Create new categories and subcategories on-the-fly directly inside the item addition form.
- **Vehicle Garage (Fleet):** Track vehicle details, VIN numbers, and specific OEM maintenance notes/fluids (e.g., oil, filters).
- **Web Auto-Fetch:** Automatically extract item metadata (title, price, store, photo) from online store links.
- **CSV Import / Export:** Easily backup, restore, or move your inventory data using CSV files.
- **Multi-language Support:** Full localization for **English**, **Norwegian (Norsk)**, and **Russian (Русский)** with automatic system language detection.
- **Data Privacy & Control:** Self-hosted backend approach with user authentication via Firebase Auth and full **Account Deletion** feature compliant with Google Play policies.

## 🛠️ Tech Stack

- **Frontend:** React Native, Expo, TypeScript, React Navigation.
- **Styling & UI:** Custom Theme Context (Dark / Light mode support).
- **Backend & Auth:** Firebase Authentication & Firestore (optional cloud sync / local AsyncStorage).
- **Utilities:** Expo Camera, Expo File System, Expo Sharing.

## ⚙️ Getting Started Locally

If you want to run or build the project from source:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/korkh/smartLedger.git](https://github.com/korkh/smartLedger.git)
   cd smartLedger

```

2. **Install dependencies:**
```bash
npm install

```


3. **Run the development server:**
```bash
npx expo start

```
